# 开发复盘：AI-CAE 物理智能计算引擎 (Project Crack)

## 1. 项目背景与目标
将传统的、显存消耗为 $O(N \times T)$ 的有限元损伤演化求解器，重构为显存占用仅 $O(N)$ 的**物理结构化、计算轻量化**的自适应演化引擎。旨在解决大规模非结构化网格在断裂模拟中的“数值崩溃”与“显存爆炸”问题。

## 2. 核心技术架构
本引擎采用“双引擎驱动”架构：
*   **物理引擎 (Term A)**：基于符号化预计算（SymPy/C++），处理弹性本构。
*   **智能引擎 (Term B)**：基于局部自动微分（Autograd/Local），处理损伤各向异性演化。

## 3. 开发实施路径细节

### 第一阶段：架构重构与一致性论证
*   **核心逻辑**：通过将切线算子 $\mathbf{C}^{ep}$ 分解为“已知的解析项 (物理)”+“可微的神经梯度项 (AI)”，规避了对整个非线性路径的计算图追踪。
*   **结论**：实现了计算复杂度从 $O(N \times T)$ 到 $O(N)$ 的降维。

### 第二阶段：数值稳定性加固
*   **痛点**：在裂纹贯通点，$D=1.0$ 导致刚度矩阵 $\mathbf{K}$ 奇异，且指数函数产生 `overflow`。
*   **解决方案**：
    *   **残余刚度**：引入 `residual_stiffness = 1e-6`，保证矩阵始终正定。
    *   **指数截断**：对 Mazars 损伤准则中的 `exp()` 输入进行 `clip` 处理。
    *   **演化阻尼**：增加损伤演化阻尼系数（Damping=0.2），防止裂纹瞬间突变导致的数值不稳定性。

### 第三阶段：几何一致性与域约束
*   **计算域对齐**：复刻了原 `brazilian_disc_v1` 的 `active_mask` 几何筛选逻辑，确保物理计算仅在圆盘区域执行。
*   **可视化修正**：采用 `np.nan` 遮罩技术，确保圆盘外部区域在视觉上完全剔除，与计算域几何严格对应。

## 4. 技术实施要点总结

| 阶段 | 关键技术点 | 复盘总结 |
| :--- | :--- | :--- |
| **范式对齐** | 算子解耦 (Term A + Term B) | 成功消除了全局计算图依赖。 |
| **数值稳定** | 残余刚度 + 指数截断 | 消除了 `nan` 错误与奇异矩阵警告。 |
| **几何一致性** | 单元几何掩膜 (Masking) | 修正了计算域与可视化映射脱节的问题。 |

## 5. 后续开发路线图 (Roadmap)
1.  **完全 Matrix-Free 化**：将 `spsolve` 彻底替换为 `PCG` 迭代求解器。
2.  **高性能算子并行化**：利用 `torch.vmap` 对损伤微分进行单元级并行加速。
3.  **正则化处理**：引入各向同性正则化以消除在极细非结构化网格下的数值噪声。
